# EE114 Lab 4: Investigating PID Control

Web interface for Lab 4 of EE114 (Maynooth University). It replaces the Simulink/MATLAB workflow:
the PID controller runs on the Arduino Nano of the balance-beam and ball-in-a-tube rigs, and the
page sends the gains, plots the measurements and produces the lab report.

**Open it:** https://thalitanazare.github.io/EE114/

- `study.html`, the **study edition**, is for preparation at home. It has several simulated systems, live sliders with a pole map, self-test questions with feedback, and emulated rigs.
- `lab.html`, the **lab edition**, is for the lab session. It has step-by-step tasks, the real rigs over USB (Web Serial) and the report, which you print or save as PDF.

Use Google Chrome or Microsoft Edge. Everything runs in the browser, and no data are uploaded.
